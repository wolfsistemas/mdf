# Assets públicos

Coloque aqui o arquivo **`logo.png`** (logo da sua empresa) para ele aparecer no
cabeçalho e no rodapé do documento de orçamento impresso.

- Arquivo esperado: `public/logo.png`
- Caminho servido: `/logo.png`
- Formatos aceitos: PNG com fundo transparente ou claro (o documento é claro).
- Recomendado: altura efetiva de ~120–200 px (o CSS limita a 52 px no layout).

Enquanto o arquivo não existir, o documento mostra o monograma texto
"MDF ATELIER" no lugar do logo — sem quebrar a impressão.
