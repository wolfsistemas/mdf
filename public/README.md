# Assets públicos

A logo da marcenaria agora pode ser enviada na aba **Config** do app
(fica nas configuracoes da oficina). O arquivo abaixo e so um fallback.

- Arquivo esperado: `public/logo.png`
- Caminho servido: `/logo.png`
- Formatos aceitos: PNG com fundo transparente ou claro (o documento e claro).
- Recomendado: altura efetiva de ~120–200 px (o CSS limita a 52 px no layout).

Enquanto nao houver logo enviada nem este arquivo, o documento mostra o
monograma texto "MDF ATELIER" — sem quebrar a impressao.
